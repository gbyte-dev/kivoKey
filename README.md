# KevoKey (KivoKey) - Mobile Car Key Service

A full-stack web application for on-demand mobile car key replacement, key fob programming, and lockout services.

## Project Structure

```text
KevoKey/
├── frontend/    # Next.js 16 + React 19 + TypeScript + Tailwind CSS v4
├── backend/     # Backend APIs and services
└── README.md
```

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
